# 228:78 Application for Leave To Issue.
Any such common carrier by rail which may apply to the department for authority to issue such securities shall file with its application a statement in reasonable detail, showing the actual cost already incurred and the estimated cost to be incurred for any of the purposes for which such securities are to be issued and the actual cost already incurred and the estimated cost to be incurred for such purposes.
Source. 1985, 402:14.
