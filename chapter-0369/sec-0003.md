# 369:3 Application for Leave to Issue.
Any such public utility which may apply to the commission for authority to issue such securities shall file with its application a statement in reasonable detail, showing the actual cost already incurred and the estimated cost to be incurred for any of the purposes for which such securities are to be issued and the actual cost already incurred and the estimated cost to be incurred for such purposes.
Source. 1911, 164:14. 1913, 145:14. 1915, 115:2. PL 241:2. RL 291:3. 1951, 203:45 par. 3, eff. Sept. 1, 1951.
