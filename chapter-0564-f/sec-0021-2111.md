# 564-F:21-2111 Registered Agent's Change of Address.
If a registered agent changes its address to another place in this state, then the registered agent may change the address of the registered office of any foreign foundation for which it is a registered agent by filing a statement in accordance with RSA 564-F:5-504.
Source. 2017, 257:47, eff. Oct. 1, 2017.
