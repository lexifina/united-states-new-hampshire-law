# 654:30 Correcting Data Files.
After each state election, the supervisors shall use the checklist from such election to correct the standard data files to conform to any changes which are evident from the checklist. Information from the voter registration data file shall be available as provided in RSA 654:31-a.
Source. 1979, 436:1. 2004, 229:5, eff. Aug. 10, 2004.
