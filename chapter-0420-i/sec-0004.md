# 420-I:4 Reports to Insurance Commissioner.
Each managed care insurer shall file a report in form and containing such information as the insurance commissioner prescribes when requested by the commissioner. Such report shall include the name of the managed care insurer, its affiliates, a description of each exclusive arrangement to which it is a party and, as applicable, the date on which exclusive arrangement has been or will be terminated.
Source. 1996, 134:2. 2000, 166:4, eff. July 22, 2000.
