# 527:4 Extension of Return Day.
The superior court, on application and notice to the debtor may order the return day of an execution issued by the court to be changed to any subsequent return day as justice may require; which order shall be recorded upon the clerk's record of the judgment and execution.
Source. GS 216:4. GL 235:4. PS 231:4. PL 343:4. RL 399:4. RSA 527:4. 1955, 104:2, eff. April 27, 1955.
