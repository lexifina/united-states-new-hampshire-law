# 662:6 Delegates to State Party Conventions.
At every state primary election, the voters shall elect delegates to each state party convention in the same manner and in the same proportion as state representative districts.
Source. 1979, 436:1. 1982, 29:2; 43:8. 1983, 248:5; 282:2; 317:2; 424:6. 1985, 31:2. 1992, 183:8. 2002, 28:1. 2012, 63:1, eff. May 14, 2012. 2022, 10:1, eff. Mar. 23, 2022.
